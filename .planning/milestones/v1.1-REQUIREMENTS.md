# Requirements Archive — Milestone v1.1: Submission-Based Quiz Flow

## Requirement Outcomes

All 14 requirements validated and shipped.

### Submission Link
- [x] **SUB-01**: Admin can generate a unique submission link from the admin dashboard — Validated
- [x] **SUB-02**: Admin can copy submission link to clipboard with one click — Validated
- [x] **SUB-03**: Admin can see how many submissions have been received — Validated
- [x] **SUB-04**: Admin can preview individual submissions (name + photo) before closing — Validated

### Worker Submission
- [x] **WORK-01**: Worker can visit submission link, enter their name, and upload a desk photo — Validated
- [x] **WORK-02**: Worker sees a confirmation page after successful submission — Validated
- [x] **WORK-03**: Duplicate names are prevented (worker warned if name already taken) — Validated

### State Management
- [x] **STATE-01**: Quiz enforces states: collecting submissions → closed → playable — Validated
- [x] **STATE-02**: Admin can close submissions via a button on the admin dashboard — Validated
- [x] **STATE-03**: Workers cannot submit after submissions are closed — Validated
- [x] **STATE-04**: Players cannot play the quiz until submissions are closed — Validated

### Auto-Generation
- [x] **GEN-01**: Questions auto-generate from submissions when admin closes — Validated
- [x] **GEN-02**: Each submission becomes one "Whose desk is this?" question with the desk photo — Validated
- [x] **GEN-03**: Each question shows 4-5 random name choices including the correct answer — Validated

## Deferred to Future Milestones
- Worker can update/replace their submission before closing
- Admin can reopen submissions after closing

## Out of Scope (Confirmed)
- Automatic closing (deadlines/thresholds) — admin button only
- OAuth or user accounts — keep PIN-based auth
- Real-time submission notifications — admin refreshes manually
