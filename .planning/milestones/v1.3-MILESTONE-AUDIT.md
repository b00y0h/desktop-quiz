**Status: ✓ Complete**

```
Dashboard loads → GET /api/super-admin/quizzes → getAllQuizzesWithStats
  → Postgres queries (quizzes + counts) → JSON response → table renders

```

```
Click "Delete" → confirm() dialog → DELETE /api/super-admin/quizzes/[id]
```
