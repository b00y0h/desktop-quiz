# Milestone v1.2: Postgres Migration

**Status:** ✅ SHIPPED 2026-01-28
**Phases:** 5-7
**Total Plans:** 10

## Overview

Migrate quiz data storage from Vercel Blob JSON files to Vercel Postgres for improved performance and reliability, while keeping image uploads on Vercel Blob.

**Target changes:**
- Replace JSON blob storage with Postgres database
- Eliminate CDN caching issues causing stale reads
- Maintain all existing user-facing functionality
- Keep image storage on Vercel Blob (no change)

## Milestone Summary

**Decimal Phases:** None (clean sequential execution)

**Key Decisions:**

| Decision | Rationale |
|----------|-----------|
| Drizzle ORM over raw SQL | Type safety, relational queries, easier maintenance |
| Keep images in Blob | Large binary data better served via CDN, no benefit to Postgres |
| Idempotent migration | Safe re-runs, can restart on failure without data duplication |
| Cascade deletes in schema | Clean quiz deletion without orphaned records |
| Preserve store interface | Zero API route changes needed, reduced risk |

**Issues Resolved:**

- CDN caching causes stale reads on Vercel Blob `list()` calls — RESOLVED
- Submission token lookup required workaround due to Blob limitations — RESOLVED
- Undefined array access bug in migration script — FIXED with null checks

**Issues Deferred:** None

**Technical Debt Incurred:** None
