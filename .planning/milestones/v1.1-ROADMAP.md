# Milestone v1.1: Submission-Based Quiz Flow — Archive

## Summary
Allow workers to self-submit desk photos via a unique link, then auto-generate quiz questions from those submissions.

## Key Accomplishments
1. **Submission infrastructure** — Admin generates unique submission links; workers upload desk photos with name
2. **Duplicate name prevention** — Case-insensitive duplicate detection with client and server validation
3. **Submission preview** — Admin gallery with thumbnails, names, count, and refresh
4. **State management** — Enforced quiz lifecycle: collecting → closed → active with guards on all endpoints
5. **Auto-generation** — Questions auto-created from submissions on close, with 4-5 randomized name options per question
